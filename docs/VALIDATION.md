## Қайталану және функционалдық тексерулер

- `make_submission.py` орындалды. Екі тәуелсіз генерация бірдей; файл генерация нәтижесімен **байт бойынша бірдей**.
- Агенттің 8 unittest тесті өтті: ресурс, тегін канал, теріс feedback, детерминизм, failed-pilot retry болмауы, >5000 сегмент бөлу, шағын контакт лимиті және NaN feedback.
- 18 HTTP/құрастыру тексерісі өтті: бет ашылуы, каталогты айналып өтуге тыйым, бөгде origin/Host, жарамсыз параметрлер, параллель запуск блоктауы, 10 seed жауабы, CSV/JSON экспорты, сегменттердің толық аудитория санымен сәйкестігі, бастапқы файлдардың өзгермегені және Git ignore.
- `node --check web/app.js` өтті.
- `start.bat` нақты іске қосылып, жергілікті серверді ашты. Осы компьютерде `.venv` дайын bundled runtime пакеттерімен тексерілді; таза компьютердегі интернет арқылы pip орнатуы жеке орындалған жоқ.
- Браузерде агентті запуск, тұрақтылық сынағы, науқан іздеу, «Неге?» диалогы, деректер каталогы және reload-тен кейін есеп қалпына келуі тексерілді.
- 390 px viewport-та негізгі бетте көлденең overflow байқалмады. Desktop көрінісінде де элементтердің қабаттасуы байқалмады. Браузер console error/warn журналы бос болды.
- `.gitignore` деректерді, ұйымдастырушы кодын, `.venv` және runtime есептерін алып тастайтыны тексерілді. Жергілікті Git `main` тармағымен басталды; commit/push жасалған жоқ.

## Шектеулер

Visual Studio GUI-дегі F5, GitHub-тағы нақты push/Actions, басқа операциялық жүйе және жасырын финал ортасы осы машинада тексерілген жоқ. Жобада соларға арналған конфигурация мен нұсқаулық берілді. 100% қатесіздік немесе эксклюзивтілік кепілдігі берілмейді.

Машина оқитын толық есеп: [validation-results.json](validation-results.json). HTTP интеграциялық тексерістер әзірлеу кезінде жергілікті серверге орындалды; күнделікті қайталау командалары README-де берілген.

# QamqorNet

QamqorNet — қаладағы ұялы байланыс сапасы туралы өтінімдерді жинайтын шағын жоба. Тұрғын байланыс мәселесін жібереді, ал өтінім SQLite дерекқорында сақталады.

## Іске қосу

Компьютерде Python 3 орнатылған болуы керек. Қосымша кітапхана орнатудың қажеті жоқ.

1. Осы жобаның бумасын ашыңыз.
2. Терминалда `python server.py` командасын орындаңыз. Windows-та `py server.py` деп те іске қосуға болады.
3. Браузерді ашып, [http://127.0.0.1:8000](http://127.0.0.1:8000) мекенжайына кіріңіз.
4. Мәселе жіберіп көріңіз. Бетті жаңартқаннан кейін өтінім тізімде қалады.
5. Серверді тоқтату үшін терминалда `Ctrl+C` басыңыз.

## Файлдар не үшін керек?

- `index.html` — сайттың көрінісі және браузердегі әрекеттер.
- `server.py` — Python веб-сервері. Бетті ашып, өтінімді қабылдайды және дерекқорға жазады.
- `qamqornet.db` — іске қосқанда автоматты түрде жасалатын SQLite дерекқоры. Бұл файлда өтінімдер сақталады.

## Дерекқор құрылысы

`reports` кестесінде әр өтінім бір жол болып сақталады:

| Баған | Мәні |
| --- | --- |
| `id` | Өтінімнің бірегей нөмірі |
| `issue_type` | Мәселенің түрі, мысалы «Сигнал әлсіз» |
| `location` | Көше немесе аудан |
| `operator` | Ұялы байланыс операторы |
| `status` | Өтінімнің күйі |
| `created_at` | Өтінім жіберілген уақыт |

Алғаш іске қосқанда кестеге мысал өтінімдер бір рет қосылады. Жаңа өтінімдер `index.html` → `/api/reports` → `server.py` → `qamqornet.db` жолымен сақталады.

## Қазір жоба нені көрсетеді?

Қала картасы, операторлар рейтингі және жылдамдық көрсеткіштері — хакатонға арналған үлгі деректер. Өтінімдерді қосу және сақтау жұмыс істейді. Нақты оператор желісінің өлшемдері қосылмаған.

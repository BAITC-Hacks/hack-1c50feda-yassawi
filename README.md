# BeeGrowth Agent

**HackAlem AI · Beeline Tariff Marketing Campaigns**

BeeGrowth помогает маркетинговому аналитику выбрать аудиторию, целевой тариф и канал коммуникации при ограниченных бюджете и числе контактов. Агент проверяет гипотезы небольшими пилотами и возвращает план из 1–10 кампаний.

Целевая метрика — дополнительный ARPU по уникальным абонентам минус стоимость всех коммуникаций, включая пилоты. Исходная сумма `predicted_arpu` не является доходом агента.

**Все данные синтетические.** Приведённые результаты относятся к локальной мок-среде. Они не описывают реальный бизнес Beeline и не гарантируют прибыль или балл скрытого судейства.

## Пользователь и сценарий

Основной пользователь — аналитик маркетинга, который готовит тарифные кампании на следующий месяц.

1. Среда передаёт профиль аудитории, тарифы, каналы и остатки ресурсов. В текущем профиле 23 441 абонент; размеры вычисляются из данных.
2. История смен тарифов другой выборки даёт начальные гипотезы. Агент не считает её истинными эффектами текущей аудитории.
3. Агент вызывает `env.run_pilot`, получает шумные наблюдения и обновляет оценки для выбранных аудиторий, тарифов и каналов.
4. Он выбирает непересекающиеся финальные аудитории под оставшиеся ресурсы и возвращает кампании с официальными фильтрами.
5. Официальный скрипт создаёт CSV. Демо показывает пилоты, план, прогнозы и локальную оценку отдельно.

## Архитектура и алгоритм

| Компонент | Назначение |
|---|---|
| `agent.py` | Всё вычислительное ядро: `Agent().act(env) -> list[dict]` |
| `environment.py`, `mock_environment.py` | Публичная среда и её локальная фабрика, предоставлены организаторами |
| `scoring_core.py`, `local_eval.py` | Официальная локальная оценка после завершения агента |
| `make_submission.py` | Генерация submission с фиксированным seed=42 |
| `demo_app.py` | Необязательный интерфейс Streamlit на русском |
| `split_eval.py` | Внешняя диагностика пилотов и добавочного вклада финала |

Агент читает только публичные данные и наблюдения. Оценщик не передаёт ему истинные эффекты или внутренние ID пилотов. Численное решение работает без LLM, API-ключей и сетевых запросов.

**Гипотезы.** Базовая ячейка — `current_tariff × arpu_segment`. Для неё вычисляются размер и сумма `predicted_arpu`; слишком большие аудитории разбиваются разрешёнными фильтрами по данным и звонкам. Историческое изменение ARPU сглаживается 30 псевдонаблюдениями слабой гипотезы по цене. На ячейку выбираются три целевых тарифа и рассматриваются доступные каналы. Частота состоявшихся переходов не используется как вероятность отклика.

**Данные.** Дубликаты истории удаляются только в памяти. Строки с исходным ARPU ≤ 0 или недопустимыми значениями исключаются; относительное изменение ограничивается диапазоном [−1, 2]. Из 14 823 строк истории остаются 13 410 допустимых. Исходные CSV не переписываются. [Полный аудит](diagnostics/data_audit.json) и [проверка истории](diagnostics/stabilization/history_and_integrity.json).

**Оценки.** Начальная вероятность отклика 0.15 — слабое предположение, а не измеренная конверсия. Для каждой гипотезы ведётся отдельная нормальная оценка с начальным std=0.20. Пилот обновляет её с дисперсией наблюдения `0.804² / n`, где `n` — фактически возвращённое число абонентов. Коэффициент канала применяется к начальной гипотезе; наблюдаемый эффект уже включает канал и повторно не умножается. Критерий `mean - std` — поправка на риск, не гарантия прибыли.

**Разведка основной версии.** Сначала исследуются до шести разных ячеек, затем — преимущественно неоднозначные повторы и краткая проверка других каналов лидеров. Начальный пилот рассчитан на 100 человек, повторный размер зависит от неопределённости и ограничивается аудиторией и ресурсами. Внутренний потолок — 16 пилотов, до трёх на гипотезу. Перед каждым вызовом сохраняется резерв на целую финальную кампанию. Ограниченность поиска после шестого пилота остаётся известным недостатком основной версии.

**Финал.** Прогноз полного охвата кампании равен `mean × сумма predicted_arpu − стоимость контактов`. Жадный выбор учитывает поправку на риск, бюджет, контакты и пересечение финальных аудиторий. При отсутствии положительной оценки используется допустимый резервный план с возможным убытком. Прогноз не скорректирован на пересечения с пилотами, поэтому его нельзя называть фактическим добавочным вкладом финала.

Одновременно проверяются лимиты: 1–10 финальных кампаний, до 5000 абонентов на кампанию, 15 000 контактов и 100 000 у.е. вместе с пилотами; ограничения среды — до 20 пилотов по 10–200 человек. При математически невыполнимых входах, например пустой аудитории, агент возвращает пустой план с причиной в журнале. На проверенных штатных данных план допустим.

## Установка зависимостей

Для закреплённых зависимостей нужен Python ≥ 3.12. Проверенная конфигурация: Python 3.14.6, NumPy 2.5.3, pandas 3.0.6, Streamlit 1.64.0. Выполняйте команды из корня репозитория в PowerShell:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip check
```

Если установленный Python доступен как `python`, первая команда может быть `python -m venv .venv`. Активация окружения не требуется. Установка пакетов требует доступа к PyPI; после установки агент, оценщик и демо работают локально. Виртуальное окружение не переносится между машинами и не включается в Git.

`numpy` и `pandas` нужны ядру и среде, `streamlit` — демо и его тестам. Остальные прямые импорты относятся к стандартной библиотеке Python или модулям репозитория.

## Демонстрация

```powershell
.\.venv\Scripts\python.exe -m streamlit run demo_app.py --server.address 127.0.0.1 --server.port 8501 --server.headless true --browser.gatherUsageStats false
```

Откройте `http://127.0.0.1:8501` на этом компьютере. Команда привязывает сервер только к локальному адресу и отключает сбор статистики использования; автоматически браузер не открывается. Для остановки запущенного в терминале демо нажмите `Ctrl+C`.

Нажмите «Запустить агента». Реализованы обзор аудитории, выбор seed, наблюдения пилотов, таблица финального плана, прогнозы агента, локальный скоринг после завершения агента и журнал объяснений. Отчёт запуска можно скачать в JSON; отдельная кнопка создаёт официальный CSV через `make_submission.py` и даёт скачать его.

Новый запуск использует корневой `agent.py`. Сохранённые результаты связаны с его SHA-256 и сбрасываются при смене версии. Переключение элементов страницы не запускает новые пилоты.

[DEMO.md](DEMO.md) содержит двухминутный сценарий. Добавочный вклад финала показывается из сохранённой раздельной диагностики: отдельной карточки для него в интерфейсе нет.

## Ограничения

- Основная стратегия почти перестаёт исследовать новые гипотезы после шестой проверки. Она не проходит экспериментальное требование продолжать поиск после шести отрицательных пилотов; отдельный тест честно фиксирует это поведение.
- Исторический top-3 может пропустить хороший тариф. История относится к другой выборке; слабая вероятность отклика не измерена по маркетинговым предложениям.
- Каналы оцениваются независимо, финальный выбор жадный. Глобальный оптимум не гарантирован.
- Прогноз не учитывает пересечения с уже проведёнными пилотами и может существенно расходиться с фактическим локальным эффектом. Шум может привести к убыточному финалу.
- Мок-оценка проверяет механику и поведение на синтетических эффектах, а не будущий результат скрытого судейства.
- В guide указано 14 824 смены тарифа, фактически в CSV — 14 823. В данных есть пропуски и недопустимые исходные ARPU; обработка отражена в аудите.

## Решение проблем

Если `python` выдаёт `The file cannot be accessed by the system`, это может быть недоступный Windows alias. Используйте установленный интерпретатор или launcher `py`. На машине разработки рабочий Python находился в `D:\anaconda\python.exe`; это особенность этой машины, не зависимость проекта.

Ошибки установки из-за недоступности PyPI требуют сетевого доступа. Не меняйте глобальные пакеты: устанавливайте зависимости в локальное `.venv`. Все команды проекта запускайте из корня репозитория, поскольку официальные скрипты используют относительные пути к данным.

Старый `verify_artifacts.py` содержит чтение исходного манифеста с абсолютными Windows-путями; он не входит в обязательный сценарий сдачи. Проверенная переносимая загрузка приложения не требует этого скрипта, архивов или личных путей.

Состав проверенного локального коммита и порядок сдачи: [SUBMISSION.md](SUBMISSION.md). Отправка в командный репозиторий отложена по решению пользователя: в удалённой `main` обнаружены новые изменения команды, затрагивающие агента, демо и тесты. Их интеграция требует отдельного согласования.

QADAM APPROACH

Тарих — бағыт. Пилот — дәлел.

Тарих басқа аудиторияға тиесілі. Сондықтан тарихи ARPU өсімі соңғы пайданың болжамы ретінде тікелей қолданылмайды: ол тек тексерілетін гипотезалардың ретін анықтайды.

1. Сенімділікті ескеретін барлау

Агент алдымен әртүрлі сегменттерді зерттейді. Кейін әсері әлі белгісіз, бірақ әлеуеті жоғары бағыттарға қайта оралады. Іріктеме 10–200 шегінде бейімделеді.

2. Сақтықпен бағалау

Пилот әсері нөлге қарай жұмсартылып, іріктеме көлеміне тәуелді белгісіздікпен бағаланады. Төменгі баға = орташа әсер − z × стандарттық қате. Бұл қалыпты жуықтауға сүйенеді; финалға кепілдік бермейді.

3. Қайталанбайтын портфель

Әр сегментке ең көбі бір науқан таңдалады. Шектеулі beam search бюджет, контакт саны және 10 науқан лимитін бірге тексереді. Бұл — жуық оптимизация, математикалық дәл максимум емес.

4. Каналдың өз бағасы бар

Каналдар қоғамдық conversion_multiplier және байланыс құнымен салыстырылады. Басқа каналға ауыстырылған болжам жеке белгіленеді: әр канал тікелей пилоттан өтпеген болуы мүмкін.

ҚОЛДАНУ ЖОЛЫ

Бір цикл. Төрт қадам.

  1. «Шолу» бетінде seed пен сақтық режимін таңдаңыз.
  2. «Агентті іске қосу» батырмасын басыңыз.
  3. Науқандардың себебін, пилоттар мен шығынды тексеріңіз.
  4. Жоспар CSV және аудит JSON файлдарын экспорттаңыз.

Хакатонға тапсыру

Интерфейс CSV-і — таңдалған сценарий. Ресми қайталанатын файлды жоба қалтасында жасаңыз:

python make_submission.py

Тексеру:

python local_eval.py --runs 10

Кодты қорғау

GitHub репозиторийін private етіп жасаңыз. Кілттерді, қатысушы деректерін және runtime есептерін қоспаңыз. Ашық кодтың көшірілмейтініне кепілдік жоқ.

Дұрыс түсіндіру

Бұл LLM чат-боты емес: дерек оқитын, пилот жүргізетін, нәтижеден үйренетін статистикалық шешім агенті. Интернет пен ақылы API керек емес.

# Данные для формы «Сдать решение»

**Название проекта:** BeeGrowth Agent

**Кейс:** Beeline Tariff Marketing Campaigns

**Описание проекта:**

BeeGrowth Agent помогает маркетинговому аналитику выбирать аудитории, тарифы и каналы кампаний при ограниченных бюджете и числе контактов. На предоставленных синтетических данных агент формирует гипотезы из истории смен тарифов, проводит небольшие пилоты и обновляет оценки по их шумным наблюдениям. Затем он выбирает план кампаний, который официальный скрипт сохраняет в `submission.csv`. Локальная демонстрация отдельно показывает пилоты, план, прогноз агента и результат оценщика; локальные результаты не гарантируют прибыль или балл скрытого судейства.

| Поле | Значение |
|---|---|
| Репозиторий команды | https://github.com/BAITC-Hacks/hack-1c50feda-yassawi |
| Ветка с проверенной версией | `main` **локально**; отправка этой версии отложена |
| Официальный файл | [`submission.csv`](submission.csv) в корне репозитория |
| Публичное демо | Отсутствует; публичное размещение не выполнялось |

**Перед отправкой формы:** проверенная BeeGrowth ещё не опубликована в командной `main`. Удалённая ветка содержит изменения команды, отличающиеся от локальной версии. Сначала нужно согласовать их интеграцию, отправить проверенную версию обычным push и подтвердить совпадение хешей локального коммита и удалённой ветки. Нельзя указывать текущую удалённую `main` как уже опубликованный проверенный BeeGrowth.

Локальный запуск для проверки, из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m streamlit run demo_app.py --server.address 127.0.0.1 --server.port 8501 --server.headless true --browser.gatherUsageStats false
```

Адрес `http://127.0.0.1:8501` доступен только на том же компьютере и **не является публичным демо**.

После подтверждённой публикации: **страница треков → Beeline Tariff Marketing Campaigns → «Сдать решение» → название и описание выше**. Сдача на платформе пока не выполнена и не подтверждена; форму в рамках этой подготовки автоматически не отправляем.
